# <img src="https://raw.githubusercontent.com/VedalAI/neuro-sdk/refs/heads/main/Assets/icon.png" width="29" style="vertical-align:middle;"> Neuro-sama Integration Mod for Buckshot Roulette
This mod allows [Neuro-sama](https://twitch.tv/vedal987) to play Buckshot Roulette by communicating with the game through a websocket.

Check out the [Neuro SDK](https://github.com/vedalai/neuro-sdk) to see how to create similar integrations for other games.

> [!Note]
> This is just a reference repository containing the source code of the mod itself. Due to how the mod is setup, we cannot open source the real repo because it contains copyrighted game assets. Since base-game scripts are not included in this repo, patches aren't included either. This repo is meant to be used just as a reference.
